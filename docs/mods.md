# The mods

Each mod keeps its own documentation beside its code, under `mods/<mod>/docs/`,
so nothing one mod says mixes with another. This page is where those documents
start. [install.md](install.md) covers getting any of them onto a server.

## private-chests

Every magic chest inside a base feeds every player's crafting from one shared
pool. This mod gives each container and each crafting station an owner and a
scope, so a craft draws only from containers the crafter can reach.

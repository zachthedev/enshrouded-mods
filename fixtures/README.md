# Fixtures

Worlds and the server configuration that goes with them, for the development
server. Each fixture is one directory, so a test names one fixture and gets a
reproducible starting state. `cargo xtask server seed --fixture <path>` copies
one into a build's run directory, and `cargo xtask server seed --help` names
what the directory holds.

Nothing here comes from a live installation. Fixture worlds are generated by a
development server that this repository fetched itself, and carry no passwords.

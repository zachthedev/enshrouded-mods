# Fixtures

Worlds and configuration files the development server starts from. Each fixture
is a directory holding a save slot and the server configuration that goes with
it, so a test names one fixture and gets a reproducible starting state.

Nothing here comes from a live installation. Fixture worlds are generated by a
development server that this repository fetched itself, and carry no passwords.

- `worlds/` a save slot per fixture, copied into the run directory at launch
- `configs/` an `enshrouded_server.json` per fixture, plus the mod configuration
